# たいやき バレー部模擬店 — 導入・運用手順

## 内容
- `index.html`：画面
- `style.css`：iPad向け画面デザイン
- `app.js`：注文、履歴、集計、CSV、JSONバックアップ・復元
- `manifest.json`：PWA設定
- `sw.js`：オフライン用キャッシュ
- `icons/`：アプリアイコン

## 重要な注意
このZIPだけでは、インターネット上のHTTPSサイトは自動作成されません。PWAとして初回導入するには、これらのファイルをHTTPS対応の静的ホスティングに配置する必要があります。ホスティング先のアカウント作成・公開作業は別途必要です。販売データはiPadのブラウザ内IndexedDBに保存し、アプリから外部へ送信しません。

## HTTPSホスティングへの配置
1. ZIPを展開し、`index.html`、`manifest.json`、`sw.js`、`app.js`、`style.css`、`icons`フォルダを同じ公開フォルダに配置します。
2. HTTPS対応の静的ホスティングサービスにフォルダの内容をアップロードして公開します。公開URLが `https://...` で始まることを確認します。
3. iPadのSafariでそのURLを開き、画面が表示されるまで待ちます。初回ロード時にService Workerが登録され、アプリ資材がキャッシュされます。
4. 画面右上の「オフライン資材 登録済み」表示はService Worker登録の目安です。完全なキャッシュ確認の代わりにはならないため、必ず次の機内モード試験を行ってください。
5. Safariの共有ボタンから「ホーム画面に追加」を選択します。項目名や位置はiPadOSのバージョンで異なる場合があります。
6. ホーム画面の「たいやき販売」アイコンから起動します。
7. 初回ロードとキャッシュ完了後に機内モードを有効にし、ホーム画面アイコンから起動できるか確認します。Wi-Fiだけでなくモバイル通信も無効になっていることを確認してください。
8. テスト注文を作成し、履歴・集計・CSV出力・JSONバックアップを試します。テスト注文は本番前に削除するか、バックアップ復元で本番用データを整えてください。
9. 文化祭前にJSONバックアップを作成し、iPad外の安全な場所にもコピーしておきます。

## 営業中の基本操作
1. 上部の「1日目」「2日目」で営業日を選択します。
2. 商品・販売区分ごとに＋／−を押して数量を入力します。
3. 「注文内容を確認」で数量と金額を確認し、「注文確定」を押します。
4. 保存が成功すると注文番号が表示され、入力数量がリセットされます。
5. 注文履歴では注文の修正・削除ができます。確認画面をよく読み、操作後に集計を確認してください。
6. 「設定・バックアップ」からCSVやJSONを出力できます。

## 保存・復元について
- 注文データは端末内のIndexedDBに保存します。ネットワーク経由で送信しません。
- Safariのサイトデータ消去、端末故障、OSやブラウザの仕様変更などによりデータが失われる可能性があります。JSONバックアップを定期的に作成してください。
- JSON復元には「全置換」と「追加」があります。全置換は現在のデータを置き換えます。実行前にバックアップしてください。
- CSVはExcelで開きやすいUTF-8 BOM付きです。iPadでは共有シートが表示される場合があります。共有に対応しない場合はブラウザのダウンロード先を確認してください。
- 前売りの売上金額は販売金額の集計であり、当日の入金額とは一致しない場合があります。

## 仕様上の留意点
- PWAのService Workerは通常HTTPS（またはlocalhost）でのみ動作します。`file://` でHTMLを直接開く方法は対象外です。
- ホーム画面追加の操作やオフライン保存の挙動はiPadOSのバージョンによって異なる場合があります。
- 「登録済み」の表示だけで完全なオフライン動作を保証できません。必ず実機・機内モードで確認してください。
- ブラウザの保存領域は絶対的な長期保管場所ではありません。バックアップを必須運用としてください。
